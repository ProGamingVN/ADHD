# Assets Directory

This directory is intended for images and media used in the website.

## Important Notes:
- According to the source document (noi-dung-khach.docx): "Ở mỗi ảnh hoặc video cần phải ghi nguồn"
- DO NOT copy images from the WEB Cũ directory or from the TICaware website
- All images must be either:
  1. Created originally for this website
  2. Obtained from royalty-free sources with proper attribution
  3. Used with explicit permission from the copyright holder
